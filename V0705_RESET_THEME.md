# V0.7.0.5 — Réinitialiser le thème actif

Dans l’éditeur, ouvrir **Projet → Réinitialiser le thème actuel** puis confirmer dans la fenêtre intégrée.

Effacés du profil actif : texte, apparence, badges, médias affichés, widgets, connexions, playlist, liens et animations personnalisées.

Préservés : compte et URL publique, thèmes sauvegardés localement, créations sauvegardées, fichiers de bibliothèque IndexedDB/serveur, statistiques de vues.

La réinitialisation actualise le profil actif et lance sa sauvegarde automatique (cloud en hébergé). Attention : les modifications du thème actif sont remplacées. Exporter ou enregistrer le thème avant l’opération pour pouvoir le restaurer.

À tester : annulation, confirmation, profil public après sauvegarde, restauration depuis Mes thèmes, bibliothèque média intacte, données de connexion intactes.
